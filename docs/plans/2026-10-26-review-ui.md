# Standalone Review UI Implementation Plan (C7)

> Execute with TDD/browser verification. Visual checks are batched at the end per user directive.

**Goal:** A production-quality standalone review SPA served by `reviewd`: review list, review detail with rounds, full diff, inline comments, fix-status board, report, submit/refresh, auth, dark/light themes, responsive layout, keyboard/a11y.

**Architecture:** `packages/ui` holds React components, tokens and API types; `packages/web` is the Vite standalone entry and router. The daemon serves `packages/web/dist` with SPA fallback and strict CSP. No CDN; system/self-hosted fonts with a monospace stack fallback. No DSH imports.

**Tech Stack:** React 18, React DOM, TypeScript, Vite, plain CSS modules/global tokens, Vitest + Testing Library, Playwright + axe-core.

**Spec:** `docs/design.md` sections 11.2, 14, 15; decisions D9.

## Global Constraints

- Default dark; light theme derived from the same tokens; every pair passes WCAG AA (4.5 text / 3 UI).
- Body 16px/1.5, controls 14px, metadata 13px, code 12.5px/20; 4/8 spacing scale; radius 6/10/999.
- Standalone 1440: 280 sidebar / flexible main / 320 right rail; 1024 rail collapses; 768 drawers; 320 single column, no page horizontal scroll.
- Focus visible 2px primary + 2px offset; dialogs trap focus, Escape closes, restores focus; tabs `aria-selected`; diff lines labelled; live regions for toasts/errors.
- Shortcuts: `c`, `r`, `j/k`, `[/]`, `?`, `g l`; inert in inputs/contenteditable; `data-shortcuts-off` disables.
- Motion 120/150/180/240ms, transform/opacity only, `prefers-reduced-motion` → 0.
- No CDN. CSP `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'`.
- Deep links: `/`, `/review/:id?round=#file=&line=`, `/new`, `/auth`, `/health`.
- Auth: 401 → `/auth?next=...`; token form posts `/api/auth`; cookie same-origin; never persist token in localStorage.
- Diff rendering: file rows lazy (IntersectionObserver), open file DOM ≤2500 nodes; tree/list virtualized >200 rows; skeletons reserve size.
- axe: 0 serious/critical on list, detail, submit dialog, auth, mobile 320 and light/dark.
- No `--dsw-alias-*` tokens in standalone; DSH panel adaptation is C8.
